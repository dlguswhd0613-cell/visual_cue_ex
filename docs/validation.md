# 현재 검증 결과

실제 장치 없이 클라우드에서 수행한 결과입니다.

- Python 자동 검사 34개 통과: Gabor 주파수·방향·배경, 설정·시행표, 데이터 기록, 모의 통신·중단 동작, 수동 밸브 명령과 연결 확인.
- 실제 Arduino 소스를 사용하는 C++ 가상 입출력 검사 14개 묶음 통과. 전체 100회, lick이 없는 조건, 타이머 오버플로, 통신 끊김, 늦은 자극 확인, 밸브 개방 중 정지, 수동 계속 열기/반복 여닫기 및 실험 모드와의 상호 배제를 포함합니다.
- Uno용 컴파일 성공: flash 6,578 / 32,256 bytes, SRAM 전역 변수 849 / 2,048 bytes. Arduino CLI 1.5.1, Arduino AVR Boards 1.8.8.
- Pygame의 화면 없는 드라이버로 화면·CSV를 포함한 3회 모의 세션을 완료했습니다. 자극 실제 소프트웨어 표시 간격은 2,000–2,004ms였습니다. 이후 자극 시작 확인의 허용 지연을 100ms로 강화하고 1회 모의 세션을 재실행해 정상 종료를 확인했습니다.
- 최종 모의 기록에서 시행 시작 기준 보상 9,000ms, 시행 종료 13,000ms를 확인했습니다. 전체 100회 스케치 검사에서는 총 4,660초(77분 40초)에 종료했습니다. 시작 신호 3초 + 최초 대기 90초 + 100 × 13초 + 99 × 33초입니다.

위 결과는 실제 모니터의 발광 시점이나 밸브의 유량 측정 결과가 아닙니다. Pi 4B 화면, USB 통신, lick 센서, 밸브 및 외부 기록 장비의 연결은 실제 장치에서 확인해야 합니다. 화면의 `DISPLAY_ON`/`DISPLAY_OFF`는 소프트웨어 화면 갱신 반환 시각이고, Uno TTL은 USB로 전달된 화면 확인 메시지의 수신 시각입니다.

재검사 명령은 README에 있으며, 원본 연구실 파일은 `reference/`에 보관했습니다. 원본 스케치와 새 Pi 프로그램은 통신 규약이 달라 함께 사용할 수 없습니다.
