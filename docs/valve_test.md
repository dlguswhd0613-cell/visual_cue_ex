# 물 공급 및 프라이밍 점검

`prime_valve.py`는 실험을 시작하지 않고 밸브만 조작합니다. 컴퓨터와 Uno를 USB로 연결해서 사용할 수 있으며 Pi나 디스플레이는 필요하지 않습니다. Pi에 Uno가 연결되어 있다면 Pi에서 실행해도 됩니다.

## 준비

1. 이 저장소의 최신 `arduino/HEADFIXED_ARDUINO/HEADFIXED_ARDUINO.ino`를 Arduino IDE에서 열고 Uno에 다시 업로드합니다. 이전 버전에는 수동 밸브 명령이 없습니다.
2. Arduino IDE의 시리얼 모니터와 실험 프로그램을 닫습니다. 한 프로그램만 Uno 포트를 사용할 수 있습니다.
3. 기존 D12 밸브 구동 회로와 밸브 전원을 연결합니다. D12는 구동 회로에 HIGH/LOW 제어 신호를 주는 핀이며 밸브에 전력을 직접 공급하는 핀이 아닙니다.
4. 동물 없이 배출구 아래에 물 받을 용기를 놓고 짧게 시험합니다. 계속 열기는 코일의 연속 통전 정격 범위에서 사용하세요.

## 실행

`prime_valve.py`가 저장된 폴더에서 터미널을 열고 실행합니다. Windows 예시이며 COM5는 실제 Uno 포트로 바꿉니다.

```bash
python -m pip install pyserial==3.5
python prime_valve.py --port COM5
```

Pi에서는 설치된 프로젝트 가상환경을 활성화하고 다음처럼 실행합니다.

```bash
python prime_valve.py --port /dev/ttyACM0
```

준비가 완료된 뒤 메뉴에서 숫자를 입력하고 Enter를 누릅니다. 프로그램 실행만으로 물이 나오지는 않습니다.

| 입력 | 동작 |
|---|---|
| `1` + Enter | D12를 계속 HIGH로 유지하여 밸브를 계속 엽니다. |
| `2` + Enter | 기본 300ms 열기 / 100ms 닫기를 반복합니다. |
| 작동 중 Enter | 밸브를 닫고 메뉴로 돌아갑니다. |
| `q` + Enter | 밸브를 닫고 종료합니다. |
| Ctrl+C | 밸브를 닫고 종료합니다. |

작은 펄스로 시험하려면 개방/폐쇄 시간을 바꿉니다. 아래는 30ms 열고 1초 닫기이며, 메뉴에서 `2`를 선택해야 작동합니다. 각 시간의 허용 범위는 10~60000ms입니다.

```bash
python prime_valve.py --port COM5 --on-ms 30 --off-ms 1000
```

처음에는 자동 정지 시간을 설정할 수도 있습니다. 다음 명령은 메뉴에서 선택한 모드를 3초 동안 실행한 뒤 닫고 메뉴로 돌아갑니다. `--seconds`를 생략하면 사용자가 중지할 때까지 작동합니다.

```bash
python prime_valve.py --port COM5 --seconds 3
```

HIGH는 전류 세기를 높인다는 뜻이 아니라 밸브 구동 회로에 켜짐 신호를 유지한다는 뜻입니다. 프라이밍은 배관에 물을 채우고 공기를 빼는 작업입니다. 출구에 물방울이 생기는 것뿐 아니라 배관이 물로 채워졌는지 확인하세요. 반복 개방 시간만으로 실제 물의 양을 알 수는 없습니다.

작동 중 프로그램은 Uno에 주기적으로 연결 확인 신호를 보냅니다. 이 신호가 끊기면 정상 동작 중인 Uno 펌웨어가 약 2초 후 D12를 LOW로 내립니다. 화면의 ON/OFF와 종료 응답은 제어 신호 상태이며, 유량 센서가 없으므로 물이 실제 나오는지는 눈으로 확인해야 합니다. 물 공급 점검을 종료한 뒤 conditioning 프로그램을 실행하세요.

연구실의 예전 `prime_valve.py`가 보내던 숫자 `3` 명령은 새 통신 방식과 다릅니다. 이 저장소의 `prime_valve.py`와 최신 스케치를 함께 사용하세요.
