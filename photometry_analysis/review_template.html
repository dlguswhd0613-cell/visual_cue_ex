01 · 실험 시작부터 마지막 trial 종료까지

공통 x축은 SESSION_START = 0초입니다. 회색 구간에는 photometry 기록이 없습니다. 전체 보기의 선은 표시용으로만 간소화했으며 CSV·NPZ는 원래 샘플을 유지합니다. 아래 개별 trial은 전체 해상도로 표시합니다. 반투명 청록색은 각 trial의 cue 시작–끝입니다.

구간 평균은 ITI를 포함한 실제 전체 샘플의 시간 평균입니다. 아래 trial 제외 선택은 적용하지 않습니다.

03 · 평균에 사용할 trial 선택

문 열림 등으로 제외할 trial의 체크를 해제하세요.

선택은 평균·SEM·lick raster에 적용됩니다. 이미 계산한 전처리값이나 bleaching/motion 보정 계수는 다시 추정하지 않습니다. 원본은 변경되지 않습니다.

다운로드한 파일은 브라우저의 다운로드 폴더에 저장됩니다. 이 HTML의 체크 상태는 창을 다시 열면 초기 선택으로 돌아갑니다.

04 · Trial 시작 기준 dF/F 평균

실선 = 평균, 음영 = ±SEM. 단위는 dF/F (%)입니다. trial 길이를 늘이거나 압축하지 않습니다. 선택한 모든 trial이 공통으로 포함하는 시간 구간에서 평균을 계산합니다. 길이가 다른 trial의 전체 값은 개별 trial 화면과 trial matrix에 보존됩니다. 청록색 띠는 포함 trial의 cue 시작·끝 시각 중앙값입니다.

05 · Trial 진행에 따른 변화와 early / middle / late

기본 비교값은 dF/F (%)입니다. F₀는 선택한 계산법의 분모, Signal은 측정 전압입니다. 그룹은 제외 전 완료 trial 순서로 고정합니다. 100회라면 1–33 / 34–66 / 67–100번입니다.

trial 번호 범위는 선택 평균에 적용됩니다. early/middle/late는 전체 trial을 사용하며 03번의 제외 선택을 함께 반영합니다. 세 그룹은 포함된 모든 trial이 공유하는 시간 구간에서 비교합니다. 각 그룹의 평균에 trial마다 동일한 가중치를 줍니다. 구간을 바꿔도 F₀를 재추정하지 않습니다.

청록색 띠는 각 그래프에 포함된 trial들의 cue 시작·끝 시각 중앙값입니다.

정렬 및 처리 기준

공유 D7의 cue·reward 사전 트리거를 Digital 1 상승 에지와 대응시켰습니다. TTL은 cue/reward보다 100ms 먼저 나가지만, lick에는 100ms를 별도로 더하지 않습니다.

cue 표시는 Arduino의 CUE_ON 확인 응답 시각입니다. 실제 모니터 광출력 시각을 측정한 값은 아닙니다. Arduino_ms가 없는 host 이벤트의 정렬 시각은 CSV에 비워 두었습니다.

Signal = analog_2 · Control = analog_1

SESSION_START부터 마지막 완료 TRIAL_END까지 먼저 자른 데이터에 적용합니다.

평균 파형은 TRIAL_START 기준 같은 시각의 dF/F를 trial 간 평균한 값입니다. trial별 평균 CSV는 각 trial 안의 원래 dF/F 샘플을 시간 평균한 값입니다.
